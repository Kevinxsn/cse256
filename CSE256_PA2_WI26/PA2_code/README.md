

## **Usage Instructions**

To execute the project, run the following command from your terminal:

```bash
python main.py

```

### **Functionality**

The script is designed to execute all three parts of the assignment sequentially. It will handle the data processing, model evaluation, and visualization (such as the attention maps) in a single pipeline.

### **Configuration**

If you need to adjust hyperparameters or file paths (e.g., embedding dimensions or test set locations), you can modify the parameter definitions located at the **beginning of the `main.py` file**.
